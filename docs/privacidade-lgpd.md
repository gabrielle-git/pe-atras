# Privacidade e Conformidade (LGPD)

As mensagens que as pessoas colam podem conter nomes, telefones e dados de familiares. Por isso a privacidade é tratada desde a concepção.

## Princípios adotados

- Minimização: a mensagem é usada apenas para produzir a análise no momento da requisição.
- Sem banco de dados de conteúdo: nesta versão, a aplicação não armazena as mensagens enviadas.
- Chave protegida: a credencial da IA fica somente no servidor, nunca no navegador.
- Finalidade: os dados servem apenas para avaliar o risco da mensagem, nunca para publicidade.

## Evolução planejada

Caso uma futura versão passe a registrar estatísticas (por exemplo, para um painel dos golpes mais comuns), o registro deve ser anônimo: guardar apenas os sinais e um resumo, nunca o conteúdo bruto, com retenção mínima e aviso de consentimento.
